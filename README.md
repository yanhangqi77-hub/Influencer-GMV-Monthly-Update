# 达人 GMV 更新 Skill

交付日期：2026-09-17。本包基于当前本机已安装版本，包含净件数涨佣筛选，以及“无佣金数据不纳入佣金情况汇总”的最新规则。

## 怎么使用

上传 TikTok Shop 原始订单 Excel/CSV，并发送指令：

| 指令 | 更新范围 |
| --- | --- |
| 更新最新GMV | 覆盖同一组滚动工作表，名称自动更新为订单付款日期范围 |
| 更新达人2026年9月GMV | 只更新2026-09月度归档的两个工作表 |
| 更新最新GMV，先给我预览，不写入飞书 | 生成本地结果与审计，等待确认再写入 |

最新模式示例：

- `Cleaned Orders - 260901~260910`
- `Creator GMV Summary - 260901~260910`

日期取本次清洗后有效订单的最早/最晚 Paid Time。最新模式选择文件中最新的有效付款月，始终复用原工作表ID，不为每个日期段新增sheet。月度模式使用 `Cleaned Orders - YYYY-MM` 和 `Creator GMV Summary - YYYY-MM`，不会顺带覆盖最新组。

请提供完整的当月累计订单快照。只有新增订单的增量文件不能直接覆盖，需先确认合并来源。月份不明确时请写出年月。

## 功能与口径

- 清洗重复记录、排除取消及未付款订单，按Paid Time归月。
- 按达人统计GMV、订单数、SKU数量、视频/LIVE/商品卡渠道及GMV占比。
- GMV沿用Order Amount；涨佣使用独立净件数口径，两者不混淆。
- 空达人或账号62归为Unattributed，不参与达人排名及激励。
- 保留人工合作类型、503/303/509佣金、Ad、持续时间与人工备注，按达人账号匹配，不按行号复制。
- 表头从第1行开始，冻结首行及Rank、Creator Handle两列；佣金字段使用柔和紫色表头。
- 默认不写入买家姓名、电话、地址等履约敏感信息。

## 涨佣提示

按”已付款且扣除取消、退款/退货的净件数”，按**单个产品**判断当月档位（不是所有产品合计件数）。同一售后的退款金额和退货件数不重复扣减；多件订单只有部分退款金额、无法核实件数时标待核实。

| 单产品月净件数至少 | 自然佣金目标 | 广告佣金目标 |
| --- | --- | --- |
| 10 | 12% | 4% |
| 30 | 13% | 5% |
| 80 | 14% | 6% |
| 100 | 15% | 7% |
| 500 | 18% | 8% |

明确属于15%优质定邀的达人，月净100件按18%/8%目标审核。历史高佣、特殊协议及身份不明确等情况遵循单独审核规则，完整说明见 [佣金激励规则](references/commission-incentives.md)。

系统比较目标与现有佣金，只提示需要提高的项目。候选在Rank和备注列用浅蓝色标记，备注示例：

> 涨佣金为503自然13%／广告5%（2026-09净31件；未列项目保持原佣金；资格及预算待审核，审核后生效、不追溯）

自动备注使用独立标记区块，每轮替换，不重复追加或覆盖人工文字。当前佣金缺失、复杂广告佣金无法解析或售后不明确时不输出确定涨佣建议。提示是候选，不代表已审批；不会直接改真实佣金，也不会自动降佣。

保留既有达人ID未寄样高亮（橙色底 `#FCE4D6`，表示**未寄样但出单的达人**，需关注和建联）；本包的涨佣脚本不负责重新查询“新达人跟进表-JP”或重新判断寄样状态。若需重新匹配样品记录，应明确提出并提供可访问的跟进表。

颜色说明：橙色底（B列达人ID）= 未寄样但出单的达人（需关注和建联）；浅蓝底（A排名/X备注）= 涨佣候选（资格及预算待审核）；绿色底 = 合计行；紫色表头（R:X）= 人工维护的佣金/合作字段。

## 佣金情况汇总联动

“佣金情况汇总”只纳入503、303、509、Ad至少一项有数据的达人：

- 仅有机构／AI、链接、持续时间或备注，不纳入。
- 空白、空字符串和仅空格不算数据；明确填写的0或0%算数据。
- 源表达人不会被删除；后续填写佣金会自动显示，清空四项佣金后自动移出。
- 通过在线公式联动，不改成静态复制；每次滚动表改名后检查引用与范围。

“有佣金数据”不等于“符合涨佣条件”，两类名单分别判断。

## 环境与安装

将完整的 `lark-creator-gmv-monthly` 文件夹放到目标机器的个人Skills目录，保留目录结构。常规位置为 `~/.codex/skills/`；若配置了CODEX_HOME，则使用该目录下的skills文件夹。已有同名版本时先备份再更新，不要只复制SKILL.md而漏掉脚本和规则文件。

工作流依赖Python及pandas、可用的lark-cli和飞书用户授权，以及环境中的lark-sheets、lark-shared等相关Skill；读取订单时按主Skill调用spreadsheets能力。仅复制本包不等于自动安装外部依赖或取得飞书权限。目标文档链接和稳定sheet_id已保留本机业务配置，换工作簿必须重新定位，不能复用旧ID。

本地生成脚本只输出JSON，不自行写飞书。在线读取、写入、条件格式及联动核验由助手遵循Skill执行。清除旧尾部等高风险操作仍需明确确认。

在本Skill目录下，技术人员可运行离线检查：

```powershell
python -B -m unittest discover -s scripts -p 'test_*.py' -v
```

生成包包括明细/汇总数据、样式、manifest、佣金审计和条件格式。不得将“生成成功”当成“已写入飞书”；线上更新必须回读核验。
